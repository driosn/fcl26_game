# DASH RAMBO

Twin-stick shooter. Play it in the browser:

**https://driosn.github.io/fcl26_game/**

- **Web:** WASD / arrows to move, mouse to aim, Shift / Space to dash, Esc to pause
- **Gamepad:** left stick move, right stick aim
- **Steam Deck:** download the Linux bundle from Actions and run `dash-rambo.sh`
